# 🧾 InvoiceQuick — Free Invoice Generator

A professional, fully client-side invoice generator built with HTML, CSS & JavaScript.

## ✨ Features
- 📤 Add your business info
- 📥 Add client details
- 🛒 Add unlimited line items
- 💰 Tax & discount support
- 🌍 Multi-currency (USD, EUR, GBP, RWF, KES)
- 👁 Live invoice preview
- 🖨 Print / Save as PDF
- ⚡ No sign-up required — 100% free

## 🚀 Live Demo
Deployed on Vercel: [invoicequick.vercel.app](https://invoicequick.vercel.app)

## 💻 Tech Stack
- Pure HTML/CSS/JavaScript (no frameworks)
- Zero dependencies
- Works offline

## 💼 Monetization
- Free tier: unlimited invoices
- Pro tier ($9/mo): custom logo, PDF branding, client portal
